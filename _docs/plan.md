# Plan: Household Chores Manager

## Scope decisions

| Topic    | Decision             | Notes                                       |
|----------|----------------------|---------------------------------------------|
| Users    | Roommates/flatmates  | Adults sharing a home, each with equal say  |
| Platform | Web app              | Opens in a browser and the household shares it |

## Open questions

### 1. How are chores assigned?

- **Automatic rotation**: chores cycle through roommates on a fixed schedule.
- **Manual assignment**: anyone can assign a chore to anyone.
- **Self-claim**: chores sit in a shared pool and people pick what they'll do.
- **Points-balanced**: each chore has a weight, and the app keeps everyone's workload even.
